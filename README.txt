ملفات نظام الاستئذان - النسخة المعدلة

الملفات:
- index.html
- app.js
- api.php
- config.php
- Dockerfile

قبل النشر على Render:
1) ارفع الملفات إلى GitHub واستبدل الملفات القديمة.
2) في Render > Environment أضف:
   DATABASE_URL = رابط PostgreSQL الصحيح
   ADMIN_PASSWORD = كلمة مرور الإدارة
3) نفّذ Deploy.
4) افتح:
   /api.php?action=health
5) إذا ظهر success=true، جرّب تسجيل دخول الإدارة.

ملاحظة:
كلمة مرور الإدارة لم تعد موجودة داخل app.js.
يتم التحقق منها في الخادم عبر ADMIN_PASSWORD.
